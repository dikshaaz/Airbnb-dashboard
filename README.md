# Airbnb-dashboard
This Project is an interactive Airbnb Analytics Dashboard developed in PowerBI to analyze listing performance, customer ratings and review trends. The dashboard transforms raw Airbnb data into actionable insights through dynamic visualisations, custom Dax calculations and user friendly navigation.
The report is designed to help users explore key metrics , identify patterns in customer feedback and gain a comprehensive understanding of airbnb listing performnace.

## Dashboard Structure
### Overview Page 
The overview page provides a high level summary of Airbnb performance showing the growth trends in Airbnb business across the globe through the years like growth maturity, decline etc. and how Covid-19 affected this trend.

### Rating analysis Page 
This page focuses on analyzing customer ratings and identifying performance patterns accross listings. This also includes 2 bookmarks which are linked to two different visualisations.

### Reviews Page
This page explores customer review data to uncover behavioral trends and feedback patterns. This also gives information that most of the customers wrote a review only once while some also wrote thrice. One interesting information we got here is that one customer wrote 283 reviews last two being on the same day of two different listings.
